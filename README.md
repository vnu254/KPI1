# Task Management System V3

Enterprise style task management platform.

Technology:
- PHP 8 MVC structure
- MySQL
- Bootstrap ready frontend
- REST API structure

Features:
- Authentication
- Role permission
- Department management
- Employee management
- Task workflow
- Progress tracking
- Deadline alerts
- File submission
- Evaluation
- Activity logs
- Reports

Install:
1. Import database/task_system_v3.sql
2. Configure backend/config/database.php
3. Run with XAMPP/Laragon
